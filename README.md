## 使用方法
该系列工具使用方法**极为简单**，完全 0 门槛，即使是**纯小白也能快速上手**，所有需要进行的操作**全部会在工具中提示**，按照工具的提示，**一步步操作即可**。部分老旧电脑系统可能没有 Fastboot / adb 驱动，如果提示推送 abl 分区失败，请检查是否已经给电脑安装好驱动，并开启手机上的 USB 调试，下载 Fastboot / adb 驱动极为简单，仅需上网搜索，就能快速获取，如果还是提示失败，请检查数据线，并检查手机是否正常连接，USB 调试是否可以正常工作。需要关闭后台的各种玩机工具箱

你需要根据**自己的机型**，去 release 界面下载对应工具，其中 7+ Gen 3 需下载 8s Gen3 工具包。注意要点击 show all 15 assets ，才能完整展示所有支持机型。

骁龙的几款以芯片命名的工具，均为多合一版本，适用全部该芯片小米机型。有 4 个选项，分别是 1.低版本 ； 2.高版本 ； 3.临时bl模式 ；4.OS1 模式。

如果你的系统安全补丁在 2026 年 1 月 或**更早**，但不是澎湃 1 系统，请选择 1.低版本 

如果你的系统安全补丁在 2026 年 2 月 或**更晚**，请选择 2.高版本 

如果你已经获取了临时 Root ，希望永久解锁 BL ，请选择 3.临时 BL 模式

如果你的系统是**澎湃 1** 任意版本，请选择 4.OS1 模式

其中骁龙 8 Gen 2 机型，其中一步可能需要输入内核版本，按照提示输入即可。还有一步需要你在另一个窗口输入代码，要怎么输入，工具会直接告诉你，你只需要**复制粘贴即可**。

在解锁尚未完成时，请勿拔下手机的数据线，部分机型解锁完成后，可能会提示需刷入全量包，下载一个不高于当前版本的包，刷入即可，注意**别点到回锁**，miflash 默认会回锁，不建议使用，直接点击 flash all.bat 即可，不要点击带有 lock 的 bat ，否则会被**回锁**。
